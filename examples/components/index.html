组件目录

这份目录收录纳入 manifest 的组件家族。示例优先使用现有 CSS class，保持纯 HTML/CSS、可访问和暗色兼容。

组件示例契约

ARIA 与键盘

交互组件必须暴露可访问名称、状态和键盘路径。覆盖层使用 role="dialog"，分页和步骤使用 aria-current="page"，展开控件使用 aria-expanded。

  • 焦点顺序从可见主内容开始：tabindex="-1" 用于主区域恢复焦点。
  • 当前页、当前步骤、展开状态必须有 aria 属性。
  • Esc 关闭覆盖层；焦点回收由页面 JS 或框架适配层处理。

暗色模式覆盖

组件示例依赖 styles.css 的 [data-theme="dark"] token 覆盖，不新增运行时依赖。

  • 颜色、边框、阴影和骨架屏 token 必须走语义别名。
  • 示例页保留 data-theme=""，便于跟随系统或手动切换主题。
  • 组件级新增颜色需要同时在浅色和暗色模式验证。
